# **Trabajo Final** 

# **Logro a evaluar** : 

Al finalizar el curso, el estudiante construye un proyecto en el lenguaje de programación JAVA utilizando el paradigma orientado a objetos, las estructuras de datos y algoritmos avanzados para obtener una solución determinada. 

# **Objetivos** 

Los objetivos que se esperan alcanzar con el desarrollo del presente proyecto son los siguientes: 

El estudiante desarrolla un proyecto que brinda una solución algorítmica para un problema propuesto usando las estructuras de datos. Apropiadas e implementa la solución algorítmica usando el lenguaje Java. 

# **Integrantes por grupo** 

El proyecto será desarrollado en grupal 

Cada grupo estará compuesto por 4 alumnos y debe elegir a un coordinador que lo represente. Todos los integrantes deben de subir todo el proyecto Final, que consiste en el informe en word, ppt y software. 

# **Temas del Proyecto Final** 

Tener en cuenta la siguiente consigna: 

Los temas a utilizar para el proyecto están relacionados con productos de una tienda, con salas de cines, con habitaciones de un hotel, con transporte interprovincial, etc. Debe permitir obtener importes totales de alguno de los atributos del tema a utilizar. Esta solución informática debe estar desarrollado en Java. 

# **Indicaciones específicas:** 

En base al contexto de la empresa a atender se debe establecer un problema y como afecta sus procesos. 

El estudiante plantea su solución al problema, tal que cubra la solución planteada. 

El grupo diseña la estructura de la solución organizando en paquetes las clases que tengan funciones similares. 

Analiza el contexto de la empresa, a partir del cual identificarás el problema y lo describirás. 

Revisa los siguientes temas para atender cada una de las características solicitadas para el aplicativo: 

- Arreglo de objetos 

- Arreglos de 2 dimensiones 

- Listas Enlazadas 

- Pilas 

- Colas 

- Arboles (ABB) 

Usar algoritmos de clases y objetos, arreglos estáticos, arreglos de objetos, matrices, listas enlazadas, pilas, colas, arboles (ABB). 

Trabajar con POO, arreglos de objetos y GUI 

# **Orden de ejecución y exposición** 

a)   (2puntos) - Formulario de la solución. Debe permitir navegar por todas las opciones de la solución. Incluir el nombre de todos los integrantes. 

b)   (3puntos) - Carga del arreglo de objetos, incluir opciones de Inserción, de eliminación y actualización de objetos del arreglo. También la opción de mostrar los datos del arreglo de objetos. 

c)   (3puntos) - Carga de objetos en la lista enlazada, incluir opciones de Inserción, de eliminación y actualización de objetos de la lista enlazada. También la opción de de mostrar los datos de la lista enlazada. 

d)   (3puntos) - Una opción para aplicar colas (Colas con prioridades) 

e)   (2puntos) - Una opción para aplicar pilas (tema libre para el grupo) 

f)       (3puntos) - Una opción para aplicar arboles ABB (Insertar nodos, búsqueda secuencial, búsqueda indexada. La comparación es por medio de cadenas) 

g)      (4puntos) - 2 preguntas por alumno, teóricas o sobre los temas del entregable.
